# PrismProxy 前端代码记忆

> 前端架构、关键文件位置、组件职责、样式链路与关键实现。`frontend/` 下 Vue 3 + TS + Naive UI + Pinia + Vite。教训见 [教训记忆](./教训记忆.md)；Wails 帧契约的 Go 侧见 [后端代码记忆](./后端代码记忆.md)。

## 总览与通信
- 目录：`frontend/src`（pages/、pages/settings/、components/、composables/、lib/、mocks/、stores/、review/）；Wails 绑定在 `frontend/wailsjs/`，前端引用路径 `../wailsjs/...`（pages 下）或 `../../wailsjs/...`（components 下）。
- **通信**：Go 方法经 Wails Bindings（wailsjs/go/app/App）；后端推送经 EventsOn（wailsjs/runtime/runtime）。关键事件：`proxy:start-error`、`proxy:ready`（底栏状态刷新）、`ui:open-settings`、`flow:upsert`/`flow:evict`、`project:changed`、`index-import-progress`。
- pages/ = App.vue 直接挂载的页面级；components/ = 共享件；无 vue-router。
- 构建红线：vite build 绿 ≠ 可用、模板 `}}` 冲突、多入口样式红线 → 见教训记忆 3/13/14。

- **AppHeader.vue**（40px）：ProjectSwitcher、流计数/暂停刷新/清空、视图切换按钮（review 态文案「返回抓包」）、GitHub（runtime.BrowserOpenURL，浏览器降级 window.open，内联 octocat SVG 无 @vicons）。无 props/emits 直用 store。
- **AppFooter.vue**（28px）：过滤栏（关键字/正则/方法/状态多选，空串哨兵=全部，非法正则降级子串）、代理状态标签、监听/系统代理开关、设置按钮。自持 status/sysState/showSysSwitch。
  - defineExpose：`refreshStatus()`=并发两状态查询（含 StartError 兜底）用于热路径；`refresh()`=refreshStatus+GetSettings 读开关可见性，仅挂载时与设置保存后调。

- **SettingsPanel.vue**：左侧 n-tabs（常规/网络/ADB代理/AI 分析/解密规则/过滤规则/域名组；无项目只显全局三个），宽 560-640，内容区独立滚动；watch [show,initialTab]（面板开着外部切 tab 只切 activeTab 不 loadSettings 覆盖编辑）。系统代理实时控制不随表单保存；保存错误用全局 message，warnings 留固定 footer。autoSysProxy 默认 false。

## AI 面板（review/components/ReviewAiPanel.vue + ai-md.ts + useIntents.ts，P4+增强）
- **结构**：aside 自绘 560px 右抽屉（absolute 于 `.review-root`，position:relative）内、z-index 30、常驻 DOM + `.open` class 切 transform translateX(104%)→0 + visibility，0.28s cubic-bezier（不用 n-drawer）。四模式 tabs（explain/intent/locate/flowmap，**用 n-tab 不用自闭合 n-tab-pane**，见教训 15）；Phase 状态机 idle→streaming→done/stopped/error。
- **v-html 唯一出口** `review/ai-md.ts`（marked+DOMPurify）；locate 展示按文末 json 块标记 lastIndexOf 截断（只渲染叙述）；intent tab 不渲染 Markdown 只渲染勾选回填摘要；**正文开关 OR 语义**（勾选或开关任一为真送正文，explain/flowmap 无开关恒全量）。

- **聊天气泡（2026-09-12）**：`ConvTurn{mode?,system,user,reason,text,open,sysOpen,usrOpen,touched,finishReason,usage?}` + convTurns 数组；**in-flight 轮次用 reactive() 代理推入数组后身份稳定**（convTurns[i]===curTurn）；beginTurn（meta 帧开轮）/closeTurn（done/error/stop/unmount 全路径幂等：清 renderTimer+落盘缓冲+清空 curTurn）；mdBuf/reasonBuf 仍作 50ms 合帧 in-flight 缓冲，flush 目标改写 curTurn；**fullText 全量聚合已废（2026-09-12 审计修复）**——主 md 区=displayMd 按 ConvTurn.mode 取当前模式末轮（反向遍历），滚随 watch 依赖改末轮 text/reason.length；单条轮询 done 分支先取 mdBuf.length 再 closeTurn。token 展示：estTokens（CJK codePoint≥0x2e80 ×0.7+其他×0.25 向上取整），真实 usage 无前缀、缺失时估算带 `≈`；send 气泡头=「消息发送 · system+user 字数 · prompt tok」，recv=「模型返回 · reason+text 字数 · completion tok」。per-turn 自动开合：思考增量先到自动展开/本轮首个正文增量自动收起/手动置 touched 退出自动；finishReason=length 时 recv 气泡内暗黄截断提示。CSS：.ai-turn hairline 分隔、.ai-bubble fit-content+max-width 92%、send 右对齐品牌紫/recv 左对齐中性白、同心圆角 12px、tabular-nums。
- **单条轮询（2026-09-12）**：singleMode ref（会话级不持久化）；doStart 分支 for 循环逐条 runIntent；**done/error 帧语义降级**——itemFrame 拦截：done→flushRender+log「第 i/N 条完成」（finishReason=length 照常告警）后 return；error→直接 return（实现层 onEvent 后再 throw，循环 catch 统计 failed 续跑）；循环守卫 `seq!==runSeq||signal.aborted` 每条前检查；**候选列表循环开始快照 `ids=[...intentIds.value]` + singleTotal ref**（AI 抽屉无遮罩，运行期翻页/筛选会静默膨胀候选集）；结束后 failed>0 补「成功 X/N · 失败 Y」，failed>=total 置 phase='error'；进度 metaText 勾选时显「单条轮询 X/N 条」（phase!=='idle' 门控），intentPct 分母=intentIds.length（单条 meta.total 恒 1 会逐条跳 100%）；scopeText 动词「逐条分析/批量分析」。
