# PrismProxy 需求记忆

> 产品定位、功能范围、用户拍板的产品决策与安全红线。实现细节见 [前端代码记忆](./前端代码记忆.md) / [后端代码记忆](./后端代码记忆.md)；M13 各阶段进度见 [进度记忆](./进度记忆.md)。

## 项目定位红线
- PrismProxy（棱镜）：Windows 桌面级 HTTP(S) 调试代理（MITM 解密 + 抓包看包），单文件 exe；独立开源工具（`https://github.com/ZhangJiaLei123/PrismProxy.git`），定位/文档/commit/注释**不引入任何具体业务方名称**。

## 架构 3.0「一后台 · 多 UI」拍板（2026-09-18，唯一设计依据 doc/架构3.0设计.md，仅设计待评审未实施）
- 动机：AI 走 CLI 操作项目时，人工要能同时用 GUI 只读观测数据，互不干扰；业务生命周期不再与单个 GUI 窗口绑定。
- 四项拍板（AskUserQuestion）：①**智能一体启动**——双击 exe 后台不在则先拉起常驻后台再开 GUI，已在则只开 GUI，可重复双击开多个 GUI 窗口；②**GUI 连接时选观察（只读）/控制，控制模式全实例唯一、被占用只能观察**，第一个连接者可选控制；CLI 不被租约阻塞（AI 自动化优先），并发写冲突靠既有 rulesProject 令牌/projGen 代际乐观并发；③**GUI 旁路只读任意项目库**——后台仍单 currentProject 抓包，GUI 可挂载任意项目只读看历史/复盘（无实时），不切走 CLI 的抓包目标；④**只支持单后台**（固定 127.0.0.1:9595，不做注册中心/多实例发现）。
- 形态：`serve`（由 -headless 正名为常驻后端，-headless 保留别名一个版本周期）/ 无参=GUI 壳（不跑代理不写库，业务全走 ctlapi HTTP+SSE）/ `cli`。Wails 在 GUI 侧仅保留资产、窗口、原生文件对话框；业务绑定不再新增，逐步收薄。
- 红线：写权限后端强制（observe-only 返回 403，不靠前端置灰）；旁路挂载经 persist.OpenReadOnly 只读句柄；观察模式与旁路项目禁止发起 AI（外发）；新增 /health 可免 token 但仅回环非敏感字段；clientId 只是展示/路由标识不是密钥，安全边界仍=回环+token+endpoint 文件 0600 ACL。
- 关所有 GUI 后后台继续常驻；必须有显式停止入口（托盘为目标形态，兜底 cli serve stop）。
- **方案审计（2026-09-18，3 P1/6 P2/11 P3 全部修订回写设计文档，留痕见设计文档 §15；四项拍板 D1-D4 不变）**：①GUI 唯一例外可只读 config/ctl-endpoint.json（连接发现用）；②回环限定 CORS 仅放行 `http://wails.localhost`，随 W1 落地（GUI 壳 HTTP 化前置）；③挂载只读句柄以 projectId 全局共享+clientId 引用计数，SSE 断开 60s 宽限期后减引用；④删除-挂载并发按四步序列（标记失效→广播等待在飞→解锁关句柄→引用归零删目录）；⑤W5 拆 W5a（统一 HTTP 客户端+`PRISM_GUI_CHANNEL` 开关）/W5b（连接/租约/挂载 UI）；⑥watchSessionEnd 关机清理提前到 W1 迁 serve；⑦`/serve/stop` 仅 cli 角色（GUI 停止入口只有托盘）；⑧observe-only 403 定位为防呆权限策略而非安全边界。

## M13 复盘 × AI 分析（2026-09-09 设计稿 v1 → 09-10 v2 增补 intent；doc/复盘AI分析设计.md 唯一设计依据，偏离 §十一 须先改设计稿）
- **范围**：复盘页四模式（explain 单接口解读 / **intent 接口意图批量标注** / locate 自然语言定位接口 / flowmap 业务链路整理）+ 主窗设置抽屉新增全局「AI 分析」tab；一期不做主窗实时入口、结果不落库、不引 mermaid、不做 `cli ai`。
- **intent 模式（v2 用户拍板：批量标注 + 详情顶部摘要条展示）**：对勾选流（FlowTable 可选勾选列，仅复盘开启）或无勾选时当前已加载页**单次请求**标整批（非每流一次，控成本）；默认只送元数据+关键头不送正文，模型判不准置 `needsBody:true` 由用户手动开正文重析（不做服务端自动二轮）；SSE `intent` 事件逐条回填；前端 `useIntents` 会话级 Map 不入库刷新重算；翻页/切标签/切 scope 清空勾选。一期 intent 无「全部匹配项」服务端扩选。
- **单条轮询处理开关（2026-09-12 用户需求）**：意图模式可选逐条独立请求（每条独立 meta/预算/done），规避批量 prompt 尺寸红线；失败续跑、全失败才置 error。
- **解读目标跟随列表选中流（2026-09-12 用户需求）**：explain 面板目标=列表当前选中流（此前仅详情页/摘要条入口赋值致按钮恒禁用）；浏览类变化不打断在跑任务、结果不错挂新标签，显式解读入口才换目标重置并自动解读。
- **关面板后台续跑（2026-09-12 用户拍板「直接恢复显示正在进行中的任务」）**：关面板（X/Esc）不再停止 AI 分析，任务后台续跑、重开面板自动恢复显示进行中进度或已完成结果；隐私语义由「关面板=中止外发」改为「关面板续跑=发起时外发同意的延续」（redact 发起确认不变）；停止唯一入口=停止按钮，离开复盘视图仍自动停止。
- **AI 配置归属（关键决策，2026-09-11 随 entries 波次演进修订，原表述「apiKey 不进 SettingsView 全量 DTO」已收窄）**：全局唯一一份 OpenAI 兼容配置（baseURL/apiKey/model/temperature/timeout/maxFlows/maxKb/redact + entries 多条目），挂 `settings.GlobalSettings.AI`（跨项目，与 ADB/持久化同类）；**顶层 apiKey 不经主窗设置表单链路**——独立 `GET/POST /api/v1/ai/config`（GET 只回 hasApiKey+掩码；POST 空串=保持原 key、`__clear__`=清空），AiTab keyInput 独立存取、SaveSettings 合并不动已存 key；**entries 条目级 apiKey 随主窗设置表单往返**（AiTab 条目卡片 v-model 编辑 + SaveSettings 全量落盘，2026-09-11 拍板确认的演进，设计意图=条目卡片逐条编辑 key）；HTTP 面 aiConfigView→aiEntriesView 仅回 hasKey 永不回原文 key；apiKey 仅存 settings.json（0600）。
- **安全红线**：apiKey 仅存 config/settings.json（0600），不回传原值、不入 Prompt、不写日志；首次分析告知弹窗（数据外发到 baseURL host）；脱敏关闭每次 popconfirm；**AI HTML 不可信，v-html 全项目唯一出口（review/ai-md.ts）且必经 DOMPurify 净化**；HTML 预览 iframe `sandbox` 绝不开 allow-scripts。

## 意图关联·自动缺省适配（2026-09-16 用户拍板）
- 需求：复盘页同一接口的重复流（不同 query/时间）只需标一次意图，其余自动带出，减少批量标注量。
- 四项拍板（AskUserQuestion）：①**纯前端实时推导**——不写 flow_intents、不额外调 AI，列表加载时按「本会话已标注 + 归档库已回填」即时派生，开关一关立即恢复，零后端持久化改动；②匹配维度=**域名+方法+路径**（比用户原话「域名+路径」收紧，GET/POST 同路径语义可能不同），query 不参与；③开关=主窗设置「AI 分析」tab 全局项（settings.json 持久化、跨项目生效），非面板内 localStorage；④派生结果必须有「自动适配」弱样式小标与实判区分，点「重新分析」随时实判覆盖（实判优先于派生）。
- 边界：自动适配不增加 AI 费用、不产生新的外发；派生计展示不计入「已标注 N 条」口径（面板 intentTotalCount 只认真实标注）；后端只存开关位不消费语义。

## 动态代理池（多厂商代理 API，2026-09-16 设计拍板，唯一设计依据 doc/代理池设计.md）
- 背景：给抓包链路加动态短效代理出站，首期接 91HTTP（通用代理服务商，非业务方），架构预留多厂商，设置中下拉选择厂商+多账号。设计稿 v1 评审，六项拍板：
  1. 新增上游模式 `pool`（direct/manual/system 保留不动）；引擎从「启动固化静态地址」改「每连接经 Resolver 动态取 endpoint」，**池内换 IP 不重启代理**；切换/停用池或改监听才走现有 needRestart。
  2. **池耗尽/厂商 API 故障策略=用户可选**：direct（回退直连+UI 常驻警示，默认）或 error（拒绝出站 502，绝不暴露真实 IP）。
  3. **多 IP 池架构但 UI 默认 fetchNum=1**（抓包粘滞）；到期前自动续提+坏点切换+手动「换一个 IP」。
  4. **账密自动拉取**（测试/启用时调 order/get-info）+手填兜底；白名单/账密双鉴权均支持。
  5. 地区首期省/市手填，不做 city-list 联动下拉（预留）；SOCKS 首期 UI 不开放仅留字段。
- 扩展点：`internal/proxypool`（Provider 接口+registry），加厂商=新增 adapter+注册一行；厂商下拉由绑定 ListProxyVendors 动态提供，前端不硬编码。
- **安全红线（沿用 AI key 口径）**：secret/password 不进 SettingsView 全量 DTO（掩码投影，空=保持/`__clear__`=清空）、仅存 settings.json 0600、不打日志；代理 Proxy-Authorization 不入 Flow 记录/cURL。
- 非目标：按域名分流代理、每请求自动轮换、AI/Composer 旁路走池（v3 拍板**旁路直连+UI 提示**）、SOCKS、CLI 交互向导，首期均不做。
- **AI-CLI 全控制面（v2 增补，用户明确需求）**：CLI/控制 API 必须完整操控池，不只读——账号增改删（CLI 是落 secret 正式通道，哨兵空=保持/`__clear__`=清空，支持 --secret-file/stdin）、切换厂商适配器/账号（`proxy pool use`）、切上游模式（`proxy pool mode`）、换 IP（rotate）、试提取（test）、查状态、白名单管理。GUI/CLI 同源 app 方法不双写；命令族 `proxy pool ...`（挂现有 proxy 子命令），HTTP 前缀 `/api/v1/proxy/pool`；池为全局环境配置不受 `--project` 影响；动作命令默认返回受影响对象最新状态（AI 单轮取结果）；默认单行 JSON。详见设计稿 §8.3/§8.4。
- 待真账号联调校准：91http v1 `format=json&time=1&pw=1` 官方文档未给字段样例（code 成功值 0/200 都出现过，判成功须兼容），P5 用真账号抓真实响应回写解析夹具。
- **v3 审计修订（2026-09-16 方案审计，3 阻断/6 严重/8 一般全部修订入设计稿，决策 8-15）**，实施时必须遵守的硬约束：
  1. **首提异步化**：EnsureProxyManager 严禁在持锁路径（a.mu/projMu→a.mu）内做厂商网络 I/O（M10 同源教训），构造后后台补池；
  2. **旁路直连（用户拍板）**：AI 分析/Composer 重发/AI 探活不走池，pool 模式下直连现状 + 网络页/AI 页 UI 提示「旁路直连用真实 IP」；
  3. **Resolving 中间态**：池空区分「提取窗口期」（Resolver 等单飞上限 ResolveWaitSec 默认 5s）与「彻底没货」（才落 OnEmpty）；OnEmpty=direct 降级期报 `Degraded`+UI 黄色警示；
  4. **坏点归因三通道**：DialContext 包装计 dial 失败（目标站超时不计）、roundTrip 出口识别明文 407（记坏点+轮换+重试一次）、盲隧道 407；resolver 每次返回值过动态防环（命中判坏点）；
  5. **鉴权机制**：Go Transport 仅 URL 含 userinfo 时预置 Basic 头，不做 407 质询重发——Manager 须保证账密就绪（条目 pw=1→order/get-info→手填）；
  6. **HTTP 语义**：ctlapi client 无 patch，更新走 `PUT providers/{id}` 整体替换（哨兵仍生效）；错误码新约定 400/404/409(新增)/502；
  7. **厂商 client 三铁律**：`Transport{Proxy:nil}` 强制直连（防环境变量代理泄 secret）、独立超时（连 5s/总 10s）、不进 Flow+日志抹 query；
  8. **配置收紧**：删 ProxyPoolSettings.Enabled（唯一以 upstreamMode 为准）、WithDefaults 零值兜底（30/1/2/5s）、CLI --secret-file/stdin 为必备通道（--secret 直传仅调试）；
  9. CRUD 落盘仿 ctl_bridge SaveAIConfigPatch 独立读-改-写路径，不经 SaveSettings 表单链路；SetSystemProxy 隐式启动点也须挂 EnsureProxyManager。
