## 一、总体节奏

分 5 个阶段，每阶段独立可测、独立提交；阶段内任务按依赖顺序推进。**后端先行、契约先定、前端分两批（设置面板 / 复盘面板）**。

| 阶段 | 内容 | 出口 |
| --- | --- | --- |
| P0 | 配置层：GlobalSettings.AI + 校验 + 测试 | 配置可读写、默认值与校验有单测；无 UI |
| P1 | AI 客户端 + Prompt 纯函数（internal/ai） | client/prompt 单测全绿，零外部依赖 |
| P2 | ctlapi 接口 + 接线层 + Wails 测试连接绑定 | curl 可打通 config/test/chat（SSE）；fakeService/路由测试齐 |
| P3 | 主窗 AI 设置面板（AiTab + wailsjs 同步） | AC1/AC2/AC3 配置-测试-引导闭环 GUI 可验 |
| P4 | 复盘页 AI 能力（四模式 + 意图摘要 + 勾选 + Demo） | AC4–AC16 全过；demo 四模式可玩 |

提交粒度：每阶段 ≥1 个提交；Go 侧与前端侧分开提交；文档随阶段末尾提交。

## 三、P1 — AI 客户端与 Prompt（internal/ai，零外部依赖）

**新包**：

```text

├─ client.go        # OpenAI 兼容 Chat Completions（stream=true）+ SSE 解析
├─ client_test.go
├─ prompt.go        # 四模式 Prompt 组装 + 双预算裁剪 + 脱敏（纯函数）
└─ prompt_test.go
```

| # | 任务 | 要点 |
| --- | --- | --- |
| P1-1 | `Config`/`Message`/`Delta` 类型 + `Client.Stream(ctx, messages, onDelta)` | 设计稿 §5.2；请求体含 `stream:true`、`stream_options.include_usage:false`；**Config 含 `ProxyURL string`（接线层算好传入，ai 包不反查全局配置避免 import app 循环依赖）** |
| P1-2 | SSE 帧解析 | 逐行扫 `data:`，取 `choices[0].delta.content`；`data: [DONE]` 正常结束；`reasoning_content` 解析但不展示（预留） |
| P1-3 | 错误包装 | 非 200 读响应体（截 2KB）解析 `error.message`，输出「服务商返回 401：…」可读错误 |
| P1-4 | 超时模型 | 不用 `http.Client.Timeout`（杀流式）；首块超时 30s（与 Timeout/4 取小）定时器，收到首帧取消；整体由外层 ctx 兜底 |
| P1-5 | 出站代理（v1.1 审计修订） | **ai 包不做装配**：Transport.Proxy 仅按 `Config.ProxyURL` 设置（空=直连）；接线层（P2）按全局 UpstreamMode 算 ProxyURL——manual 取配置代理、system 取系统代理+防环排除自身（接管后防环返回空=直连语义自动继承）、direct 直连；compose 现状为调用方传 `Sender.Upstream` 字符串，无可复用独立 helper，不引 compose 依赖 |
| P1-6 | Prompt 纯函数 | 四模式 system/user 模板（设计稿 §5.4 口径）：稳定序号 `[#n]`+flowId；intent 要求每条一句话+文末 JSON 块；locate 要求文末 JSON 块；flowmap 编号步骤、推测显式标注 |
| P1-7 | 双预算裁剪 | 流数截前 MaxFlows（**按 StartedAt 降序取最近，v1.1 定稿**；后端取数后复查排序，不依赖前端传参顺序，返 truncated）；字节按 per-side 预算截断并加标注；intent/locate 贪心先丢响应体再丢请求体；CONNECT/无正文/二进制跳过标注 `[binary, N bytes]`；默认字段白名单（method/URL/status/耗时/进程/Content-Type/关键头；Authorization 只标类型；默认不送 Cookie 原值） |
| P1-8 | 脱敏正则 | 头（Authorization/Proxy-Authorization/Cookie/Set-Cookie/X-Api-Key/X-Token 等，保留 scheme）；正文 JWT/密码凭据键/手机号（前3后4）；纯函数 |
| P1-9 | 文末 JSON 块解析 | ```json {"intents":[...]} / {"matches":[...]} ``` 提取+剥离正文；缺 seq/未知 flowId/重复结果的覆盖语义；解析失败降级（仅 Markdown，不报错） |
| P1-10 | 单测 | SSE 帧拼装/`[DONE]`/错误体/首块超时/BaseURL 归一化请求 URL；脱敏固定报文断言（**AC10 的测试锚点**）；60 流+超 64KB 截断断言（**AC11 锚点**）；空/二进制正文；JSON 块正常/损坏/重复 seq |

**出口**：`go test ./internal/ai/` 全绿；`go vet` 干净。

## 七、风险与注意事项（来自既有踩坑）

1. **Wails 绑定最多 2 返回值且末位 error**——TestAIConnection 等一律单结构 DTO（M12.3 踩坑⑥）。
2. **改 ctlapi Service 接口必须同步 fakeService**，`var _ Service` 编译期断言；wailsjs 三文件即使复盘走 HTTP 也要手动同步防脏 diff。
3. **SSE server 禁 WriteTimeout/IdleTimeout**（M8.5 既有红线），AI chat 同此约束；Flush 要及时。
4. **前端 vite build 绿 ≠ 可用**：改完 grep dist 特征文案/IDE 诊断零错误（M11 白屏教训）；同文件多个 SearchReplace 不并行。
5. **apiKey 全程不入库 DTO、不进 Prompt、不写日志**；错误信息对 URL query 脱敏。
6. **取数只读归档库**：A 项目 id 在 B 项目查不到按失效处理（AC15）；composer 结果流不落归档，live* 通道与 AI 通道不同源，无需特殊处理。
7. Go module 若 go.mod 变动，先写 import 再 `go mod tidy`（GOPROXY goproxy.cn）；本期预期零新 Go 依赖。
8. PowerShell 编码红线：含中文源码只用编辑工具改，不用 Set-Content/Out-File。
9. 增量构建用 `go build -trimpath -ldflags "-s -w" -o build\bin\PrismProxy.exe .`（保留 config，不用 wails build -clean）。
